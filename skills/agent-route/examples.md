## Spend the cheaper model on work it can do

Changes: nothing; it may start a subagent or a new session.

| You type | When | You get |
| --- | --- | --- |
| `/v2:agent-route` | before a piece of work | the work weighed (light, standard, heavy), kept here or run in a subagent on the model it needs |
| "fallo con haiku" | a mechanical task | the task on Haiku |
| `/v2:agent-route alto opus the parser refactor` | you fix the effort and the model | the work run with them |
| "continua in una nuova sessione" | the conversation is long | a new session with the message that continues the work |
