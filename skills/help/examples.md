## Learn which skill does a job, and how to call it

Changes: nothing; it writes the page in the temporary folder.

| You type | When | You get |
| --- | --- | --- |
| `/v2:help` | you want the whole plugin at a glance | this page, opened in the browser |
| `/v2:help work-status` | you know the skill, not its options | the page opened on that skill |
| "quale skill uso per provare una PR?" | you know the job, not the skill | the skill that does it (`/v2:work-test`), its command, the page |
